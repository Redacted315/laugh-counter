# laugh-counter
A small desktop laugh counter app. Made with python's built-in UI library, Tkinter.

### Requirements
* Python >= 3.14
* Tkinter
* uv *(optional but recommended)*

### Installation
Download the .whl from the Releases page.
Install with [uv](https://docs.astral.sh/uv/): 
```sh
uv tool install ./laugh_counter-0.1.0-py3-none-any.whl
```

### Usage
Run the applicatgion: `laugh-counter`
